# Cellpose Plus

## Overview
Cellpose Plus is an enhanced version of the original Cellpose framework designed for cell segmentation and image analysis tasks. It leverages deep learning techniques to provide robust methods for segmenting cells in both 2D and 3D images. The framework includes various utilities for handling image preprocessing, segmentation, and evaluation, along with support for model training and testing.

## Purpose
The primary purpose of Cellpose Plus is to facilitate accurate and efficient segmentation of cellular structures in microscopy images, enabling researchers and practitioners in the life sciences to extract meaningful biological insights from complex image data. The framework supports various input data formats and offers features for denoising, augmenting images, and exploring deep learning models through an easy-to-use command-line interface and graphical user interface.
