# Image Data Processing Module

## Overview
The Image Data Processing Module is designed to facilitate the preparation and management of image datasets for cell segmentation tasks. It offers a comprehensive suite of functions that enable the normalization, reshaping, and retrieval of images and their corresponding annotations. This module is integral for structuring and accessing training, validation, and testing datasets tailored specifically for cellular imagery.

## Purpose
The primary purpose of this module is to streamline the data handling process in cell segmentation workflows. It provides functionalities for reshaping and normalizing images based on their types, obtaining file paths for training, validation, and testing datasets from various sources, and effectively managing image masks. Additionally, it integrates capabilities for converting annotations into mask formats that are essential for training and evaluating deep learning models. By optimizing data preparation tasks, this module enhances the overall efficiency and accuracy of cell image analysis.
