# Cellpose Plus

## Overview
Cellpose Plus is an advanced framework designed specifically for the task of cell segmentation in microscopy images, leveraging deep learning techniques to enhance the capabilities of the original Cellpose framework. This module provides comprehensive tools for image preprocessing, model training, and performance evaluation tailored to both 2D and 3D image formats.

## Purpose
The primary purpose of Cellpose Plus is to facilitate the accurate segmentation of cellular structures, allowing researchers in the life sciences to derive significant biological insights from complex image data. It achieves this through a range of functionalities including data preparation, model training, robust validation mechanisms, and detailed performance analysis. The framework emphasizes usability with both command-line and graphical interfaces, ensuring efficient processing and assessment of cellular images.
