# Cellpose Plus - Module v1_0

## Overview
The Cellpose Plus module v1_0 enhances the capabilities of the original Cellpose framework specifically for segmenting cells in microscopy images. This module includes a comprehensive set of functions for preparing data, training various segmentation models, and testing their performance on image datasets, both in 2D and 3D formats.

## Purpose
The primary purpose of this module is to facilitate the following functionalities within the Cellpose Plus framework: 
- Generation of pretrained model paths for quick access.
- Creation of k-fold datasets for robust model validation.
- Training of U-Net models configured for different classes and architectures, ensuring flexibility and adaptability to diverse data.
- Evaluation of model performance through thorough testing protocols, including specific functions for benchmarking timing and accuracy.
- Detailed analysis and visualization of model performance metrics, aiding users in understanding the efficacy of their segmentation tasks.
- Management of nuclei datasets for segmentation purposes, including dataset loading, masking, encoding, and decoding functionalities.

This module is designed to provide researchers with the tools necessary to achieve accurate and reproducible results in cellular segmentation applications, contributing significantly to advancements in biological image analysis.
