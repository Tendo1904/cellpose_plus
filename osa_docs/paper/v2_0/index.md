# v2_0

## Overview
The v2_0 module is a critical component of the Cellpose Plus framework specifically tailored for image preprocessing, data handling, and model training tailored for cell segmentation tasks. This module encompasses various functions that enable the manipulation of image datasets, normalization processes, and the extraction of relevant features from multiple types of image data.

## Purpose
The primary purpose of this module is to streamline the acquisition and preparation of training and testing datasets for cell segmentation. It provides mechanisms to reshape and normalize images, load data along with their corresponding masks, and retrieve files based on specific criteria such as tissue types or cell types. Additionally, it implements clustering techniques for style representations and trains networks suitable for image analysis, enhancing the efficiency of model evaluation and performance assessment in cellular image segmentation tasks.
